# 3D look test

Toon-shaded 3D Dr. Grumbles (three.js) rendered through the same headless-browser pipeline.

- `demo.html`: scene (clinic + blood-vessel fly-through), lip sync from `voice/env.json`, 2D captions on top
- `render3d.js`: `npm install` here first, then `node render3d.js` (or `node render3d.js stills 1 5 9`)
- Output: `3d-look-test.mp4` (10.6s, ~2.5 min to render)
